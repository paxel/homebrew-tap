# homebrew-tap

Homebrew tap for paxel's tools. Formulae install prebuilt binaries from each
tool's GitHub release; every release workflow pushes its own formula here, so
`brew upgrade` follows new versions.

```sh
brew tap paxel/tap
```

| Tool | Install | What it is |
|------|---------|------------|
| [claude-here](https://github.com/paxel/claude-here) | `brew install claude-here` | Run Claude Code in a project-scoped Docker sandbox with enforced git modes |
| [dedup](https://github.com/paxel/dedup-rs) | `brew install dedup` | Forensic data-inheritance triage: dedupe, diff and browse file piles |
| [whiteboxed](https://github.com/paxel/whiteboxed) | `brew install whiteboxed` | WYSIWYG editor for arc42 building-block views |
| [wiptracker](https://github.com/paxel/wipTracker) | `brew install wiptracker` | One-line always-on-top bar showing the task you are focused on right now |
| [catlog](https://github.com/paxel/cat-a-log) | `brew install catlog` (CLI) / `brew install --cask catlog` (app) | Local-first catalog for foster cats, no server, no account |

Works with Homebrew on macOS (Apple Silicon and Intel) and Linux, including
Linuxbrew inside WSL. For Windows see [scoop-bucket](https://github.com/paxel/scoop-bucket).

Everything here is generated by the release workflows of the tool repositories;
do not edit the formulae by hand.
